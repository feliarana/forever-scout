# forever-scout

This repository uses one instruction file for every AI agent, and one private file per player.
Read both before doing anything else:

@AGENTS.md
@PLAYER.md

- `AGENTS.md` — what this project is, how to set a player up, and the "read" routine.
- `PLAYER.md` — this player's profile and personal rules (git-ignored). When it does not exist,
  this is a new player: start with the onboarding in `AGENTS.md`.

If the two lines above did not load the files for you, open them yourself.
